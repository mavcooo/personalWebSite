# Personal Website

Setup iniziale per il progetto (React + Vite).

## Installazione
1. Clona il repository
2. Esegui `npm install` o `yarn`
3. Copia `.env.example` in `.env` e aggiorna le variabili
4. Avvia in sviluppo: `npm run dev`

## Script utili
- `npm run dev` – avvia vite in sviluppo
- `npm run build` – builda i file per produzione
- `npm run preview` – serve la build di produzione
- `npm run lint` – esegue ESLint e prova a correggere automaticamente
- `npm run format` – formatta con Prettier

## Struttura consigliata
- `/src` – codice sorgente (React)
- `/public` – asset pubblici (favicon, immagini statiche)
- `/assets` – immagini, icone
